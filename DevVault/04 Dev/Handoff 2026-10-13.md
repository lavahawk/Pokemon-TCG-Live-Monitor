## Gotchas
- **Limitless API: 50 requests / 5 min without a key.** Never call `play.limitlesstcg.com/api` outside `meta_sources._api_get`; urllib3 no longer retries 429s (the throttle handles them).
- `.meta_store/online_v3_*` hold decklists (~80 KB each, ~70 MB total). Cache-only rebuilds load all of them (~2–3 s), so the Meta tab's alternative views build on a thread.
- After changing `_assemble`, rebuild the installed sheet from cache: `rebuild_meta_sheet(True)`, keep `fetched_at`, write `SHEET_FILE`.
- Battle logs: old ones are cp1252. PTCGL sometimes writes targets with the wrong owner, so card names after " to / on / from " are ignored in `log_card_counts`.
- In this environment Bash heredocs containing `'` sometimes fail to parse: write patch scripts to a file (`scratchpad/patchlib.py` keeps CRLF).
