## Gotchas
- **Limitless API: 50 requests / 5 min without a key.** Never call `play.limitlesstcg.com/api` outside `meta_sources._api_get`. A 429 isn't retried by urllib3 any more (the throttle handles it).
- `.meta_store/online_v3_*` hold decklists (~80 KB each, ~70 MB total). Cache-only rebuilds load all of them (~2–3 s): they run on a thread in the Meta tab.
- Battle logs can be cp1252 (old ones): read them with `AIParseBattleLog.read_battlelog_file`.
- In this environment Bash heredocs with `'` inside sometimes fail to parse: write patch scripts to a file (`scratchpad/patchlib.py` keeps CRLF).
