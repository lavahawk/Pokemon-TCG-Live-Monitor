## What changed since v2.4.0 (all committed)

### Auto-export / blocker — [[BattleEndAutomation]] · [[AutoClicker and ContinueBlocker]]
- **BUG-037 (critical):** BATTLE LOG template matched a dark bar beside PLAY on the home screen and clicked it. Fix: OCR must read "BATTLE LOG" in the matched box (`reads_battle_log`), and unverified positions are never cached (`AutoClicker.find_in_frame(verify=…)`).
- **BUG-038:** colour-patch HUD check was backwards on the current layout. Replaced by a **settings-gear template** (`button_templates/battle_hud_gear.png`, battle 0.98–1.00, home 0.44). BATTLE LOG search also runs while the HUD shows.
- **Blocker timing:** a hidden **standby blocker** is pre-loaded when a battle starts (`--standby`, show via `Logs/.blocker_show`, ready via `Logs/.blocker_ready`, warm-up show off-screen). Measured **0.05–0.06 s** in real games (was ~1.5 s). Clicks wait for the ready signal. Blocker only appears once the game is foreground; standby is re-armed after each end screen.
- Acts on the first OCR-verified frame; in-battle polling 0.5 s.
- Verified in many real matches (battles #46–#59), incl. window resize and a mid-battle monitor restart.

### Rank OCR — [[RankDetector and BattleState]]
- Master-league points sit higher → digits were clipped (1491 read as 491). Region padded ±35% of its own height (resolution-relative), and `preprocess_rank` isolates white digits by connected components (handles sparkles/rims). Correct at 13 window sizes (874×511 → 2913×1704).
- Post-battle read now keeps retrying while the counter animates (was one attempt → `rank=None`).
- `get_max_rank`: a value counts if seen twice **or** a neighbouring reading is within 150 (Master points rarely repeat).

### Dashboard performance — [[StatsUI]] · [[OverlayUI]]
- Deck pages built **lazily** (`LazyDeckPage`), one per 120 ms in the background; pre-built 1.5 s after data loads.
- 15 s refresh skipped unless `BattleDatabase.data_signature()` changed.
- Sprite downloads moved off the UI thread (`SpriteDownloader`).
- Hub keeps the dashboard alive (close = hide) and pre-builds it 4 s after start → open in ~0.16 s, re-open ~0.02 s.
- Web tabs (Limitless dashboard, Replay, PokeData) load on first view.
- Opacity slider: static stylesheet applied once, `GlassFrame` paints the glass, dynamic rules only on title/footer → **14 ms/tick** (was 248 ms).

### Statistics — [[deck_analytics]]
- Exact Beta posterior maths (`beta_cdf`/`beta_ppf`, no normal approximations), verified vs closed form (5.6e-16) and Monte Carlo.
- `win_rate_posterior`, partial pooling of matchups toward the deck's own rate, `meta_adjusted_winrate` (post-stratified by meta share; fully-correlated uncertainty, moment-matched Beta range), `probability_above`, `verdict_from_probability`, `sample_confidence`.
- **Tie modes** (TrainerHill-style): ignore / losses / ½ / ⅓ (default) / wins — `tie_mode()`, `tie_split()`, `result_rate()`; setting `tie_mode` in `.app_settings.json`.
- **Your games are weighted** (`battle_weight`, `weighted_record`): expansion era × (Limitless tournament | league | unranked), rescaled to Kish effective n (equal weights reproduce the raw record exactly).

### Unified meta sheet — `meta_sources.py` (new)
- Sources: play.limitlesstcg.com API (online; standings W/L + **pairings → matchups**), limitlesstcg.com in-person events (statistics + full Day-2 standings, variants split from tooltips), Limitless Japan City Leagues (`/tournaments/jp`, icon-signature → archetype names).
- Expansions from Limitless card DB (EN + JP calendars; ≥90-card products). **Era from each event's legal set range** (sets become legal days after release).
- Weights (user-adjustable): online 1.0, in-person 1.75, Worlds 3.0 (boosts only in current format), Japan ×0.75, era 1.0/0.7/0.4, older dropped; size √(players/64) clipped 0.5–3.
- Per-event results cached forever in `.meta_store/`; build ~3 s from cache. Output `.meta_cache_limitless_standard.json` (schema 3): `share`, `share_en` (English-legal field), `top_share`, weighted W/L/T, `matchups`, `in_person` (Day 2 / Top 32 / Top 8 / wins / conversion / best finish), `in_person_events`.

### Preferences — `weights.py` (new)
- Advanced → **Preferences · Data Weights**: meta weights, your-game weights (league anchors, tournament, unranked), tie rule. Saves only overrides under `weights` in `.app_settings.json`. Apply recomputes your stats and rebuilds the sheet from cache.

### New tabs / views
- **Decks:** visual-first cards (estimate, vs meta, verdict), hover tooltips, `RangeBar`/`HoverCard`/`ResultStrip` animations, matchup table with Field benchmark (your archetype vs opponent on Limitless), "Too few games" under 3 games, impact ▲/▼.
- **Meta (new):** Archetypes (share ⚖, top cut ⚖, weighted record, win % under tie rule, likely range, vs field ⚖, converts ⚖, source dots) + opt-in **Matchups** matrix (lazy). ★ rows for your own decks (separate from public data). Loads in ~0.18 s.
- **Limitless TCG Live Meta:** Meta | **In-person** views (events table + archetype placings).
- **In Person (new):** Event finder & Track your homies (seagrovetcg.com), **Print your decklist** (pokedata.ovh/paper, filled via JS from the decklist captured by `decklists.py` when you Export → Copy in PTCGL).
- Icon picker rebuilt (slot tiles + one search + sprite grid, background online lookup).

### Data fixes
- pokekameshi Japan rows no longer fake W/L (BUG-027).
- Limitless meta table no longer mutates shared rows (stamped 0% on in-person-only decks).
- Deleted one misread rank row (`rank_history` id 122 = 491).

## How to verify quickly
- Monitor: `.venv\Scripts\python.exe TCGLiveMonitor.py`; play a match → `Logs\autoclicker.log` shows `Continue blocker up after 0.0Xs (standby)` … `Auto-export complete`, then `Menu OCR (after battle): … rank=…`.
- Meta sheet: `.venv\Scripts\python.exe meta_sources.py` (prints events per source and top archetypes).
- Tests: `.venv\Scripts\python.exe test_rank_weighted.py`.
- Offscreen render scripts used this session lived in the scratchpad; pattern: create `StatsWindow`, patch `save_window_geometry`, call populate methods, `grab()`.

> [!tip] Don't restart the monitor mid-battle
> Check the tail of `Logs\autoclicker.log` first (last line should be an export, not "Battle HUD detected"). A restart mid-battle recovers, but avoid it.
