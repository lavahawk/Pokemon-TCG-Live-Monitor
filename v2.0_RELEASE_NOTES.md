  - `Test_ResolutionScaling.py` - Verify OCR at your resolution
  - `Calibrate_OCR_Regions.py` - Interactive region setup tool
- **Supported:** All resolutions, window sizes, DPI settings
- **Backwards compatible:** Old pixel configs still work

## 🎯 User Experience

### First-Time Installation
1. User downloads/clones repository
2. Right-clicks `Installers\INSTALL_COMPLETE_v2.0.bat` → Run as Administrator
3. Installer checks for Python → Opens download page if missing
4. User installs Python (checks "Add to PATH")
5. Installer checks for Tesseract → Opens download page if missing
6. User installs Tesseract (default path)
7. Installer creates venv and installs packages (3-5 minutes)
8. User enters OpenAI API key when prompted
9. Installer adds Task Scheduler task for auto-start
10. **Done!** Log out/in or run manually

### Daily Usage
- **Automatic:** Just log in to Windows → Monitor starts hidden
- **Manual:** Run `Installers\Start_GUI_Mode_v2.0.bat`
- **Game launches** → Overlay appears in bottom-right corner
- **Battle ends** → Clipboard detected → AI analyzes → Database updated
- **No console windows** - Only minimal overlay visible

### Disabling Auto-Start
- Right-click `Installers\Remove_AutoStart_v2.0.bat` → Run as Administrator
- Task removed from Task Scheduler
- Can still run manually

## 🔧 Technical Details

### Task Scheduler Configuration
```batch
Task Name: PokemonTCGLiveMonitor_v2
Trigger: At log on (any user)
Action: "C:\...\BattleLogImport\.venv\Scripts\pythonw.exe" "C:\...\TCGLiveMonitor.py"
Run Level: Highest
```

### API Key Priority Order
1. `.env` file: `OPENAI_API_KEY=sk-...`
2. `.openai_key` file: `sk-...`
3. Environment variable: `%OPENAI_API_KEY%`

### Database Schema (v2.0)
```sql
battles (id, timestamp, my_deck, opponent_deck, result, my_rank, confidence, deck_source, log_file)
rank_history (id, timestamp, rank, deck_name)
session_stats (id, date, wins, losses, max_rank, min_rank)
```

### Elo Comparison Logic
```python
# OLD (v1.x - WRONG)
if current_rank < max_rank:  # Treated like ladder rank
    max_rank = current_rank

# NEW (v2.0 - CORRECT)
if current_rank > max_rank:  # Higher Elo = better
    max_rank = current_rank
```
