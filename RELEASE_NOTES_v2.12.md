# Pokemon TCG Live Monitor v2.12

Quick fixes and quality-of-life tweaks.

## Install
Grab **`PokemonTCGLiveMonitor-2.12.0-Free-Setup.exe`** below and run it.

- It ships with its own Python and Tesseract, so there's nothing else to download.
- No admin rights needed. If you're on any 2.x version, just install over it; your battles and settings stay put.
- SmartScreen will probably complain since the installer isn't signed. Click **More info → Run anyway**. The `.sha256` is there if you want to check the file.
- Windows 10 or 11, 64-bit.

## What's new
- **Rename or merge decks.** On a deck's page, click **Rename / Merge**. Type a new name to rename it, or pick another deck to merge into it, which helps when an OCR misread split one deck's battles in two. Battles, rank history, the linked decklist, and pin/star/ignore all move with it.
- **HUD size and Text size for 4K screens.** Go to Dashboard → Advanced and pick 100% to 200% for each. The app restarts to apply them.
- **Shared deck page is dark by default**, with a small light/dark button in the header that remembers your choice.
- **Trainer Gallery and Galarian Gallery card images** (e.g. Boss's Orders LOR-TG 24) now load from Limitless, in the app and on the share page.
